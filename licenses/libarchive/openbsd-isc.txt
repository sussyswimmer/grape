ISC-style notices of two pieces of OpenBSD code in libarchive 3.8.10 sources
that are compiled into Grape's bsdtar. Each piece is used only where the
system lacks its own: arc4random_buf (Windows uses bcrypt, macOS has it) and
readpassphrase (Windows has its own branch, macOS has it). So the Windows and
macOS builds normally contain neither, but the files are compiled, and the
notices are kept. Copied from the files named above them, without the C
comment markers.
